#[Project 1: When Was the Golden Era of Video Games?]( https://drew-alt.github.io/Drews-_portfolio/)

This is a project I did through data camp to advance my SQL skills, by thinking in the overall context of the gaming industry. As the videogame industry grows in scale over time, we ask if we are in the golden age of games or has it already passed ? By analyzing the entire industry by popularity we as analysts can then see if games are performing better than they ever have, or if adjustment is needed.

*Data was used from 2 tables 
*Utilized multiple statements in SQL

*Queried numeric, int, and float data
